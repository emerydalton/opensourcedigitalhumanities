# TEI texts

Store project transcriptions and editions here as TEI P5 XML. Each file should identify its source record and manuscript witness, when applicable, and include a TEI header describing the source, responsibility, and editorial and encoding practices.

Use TEI elements for manuscript descriptions, source descriptions, and textual variants where appropriate. Document uncertain readings and editorial interventions rather than silently correcting the source. Preserve the source transcription; put normalized text and other analysis-specific representations in separate, traceable outputs.
